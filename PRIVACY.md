# Privacy Policy — Lumen (ChatGPT Speed Booster)

_Last updated: 2026-09-19_

## Summary

Lumen does **not** collect, transmit, or share any personal data. There is no
account, no login, no analytics, and no remote server.

## Data handling

| Item | Detail |
| --- | --- |
| Settings | Stored locally in your browser (`chrome.storage.sync`) |
| Conversation content | Processed **only** in your browser, in memory, to reduce rendering cost — never stored by Lumen, never sent anywhere by Lumen |
| Network requests | Lumen itself makes **zero** external requests. Additional requests to third-party telemetry endpoints are blocked via declarative rules. |
| Permissions | `storage` (settings), `tabs` (find the active ChatGPT tab), `declarativeNetRequest` (telemetry blocklist) |

## Changes

Any change to this policy will be reflected in a new version of the extension
with an updated date above.
